Update Sources

All update sources are queried at the same time; the first one that responds and parses successfully is used and the rest are discarded.

    refreshTest all addAdd source

    Download Sources

    All sources start the speed test and manifest parse at the same time; the first one that responds and parses successfully is used and the rest are discarded. Speed tests can be paused while the game is running.

      refreshTest all addAdd source

      Java Runtime

      A matching Java is downloaded automatically when installing a version (Adoptium official API first, then mainland mirrors).

      JRE JDK

      Java is installed to .minecraft\runtime\<major>-<jre|jdk> (e.g. .minecraft\runtime\17-jre), so other launchers such as PCL can find it automatically. This path is fixed and needs no setting.

      Java mirrors (Adoptium package directories). On install the official API and all mirrors are resolved in parallel; the fastest one that answers wins. The list below is shown fastest-first after a test.

        refreshTest all addAdd mirror
